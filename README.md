# Pietra Garcia Studio

Site estático desenvolvido pela MLP Studio.

## Abrir no computador

Extraia o ZIP e abra o arquivo `index.html` no navegador. As imagens, fontes e dependências estão incluídas.

## Hospedar no GitHub Pages

1. Extraia o ZIP e envie o conteúdo da pasta extraída para a raiz da branch `main` do repositório. Inclua o arquivo `.nojekyll` e mantenha as pastas `assets`, `css` e `js` ao lado do `index.html`.
2. No repositório, vá a **Settings → Pages**.
3. Em **Source**, selecione **Deploy from a branch**. Escolha **main** e **/(root)**, e clique em **Save**.
4. Quando a publicação terminar, copie o endereço exibido em **Pages** para enviar à cliente.

O botão de agendamento abre uma conversa no WhatsApp. A confirmação do horário acontece na conversa.
